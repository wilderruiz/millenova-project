# millenova-project

Public engineering, architecture, experiments and development record for Millenova — a native-media music discovery and creator platform.

## Start here

- [What is published here](WHAT_IS_PUBLISHED_HERE.md) — the public/private publication boundary and agent rules.
- [Public facade implementation plan](MILLENOVA_PUBLIC_FACADE_IMPLEMENTATION_PLAN.md) — the review-first step-by-step programme used to build this repository.

This public repository is intentionally separate from the private Millenova implementation repository. Architecture and engineering decisions may be documented openly; credentials, sensitive production configuration, private user data, and exploitable operational details remain private.
